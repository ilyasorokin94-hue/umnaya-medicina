## Что не нашлось и почему

1. **Реестр лицензий Росздравнадзора** (roszdravnadzor.gov.ru/services/licenses): поиск и по ИНН 5040170382, и по номеру
   Л041-01162-50/00660328 вернул пустой ответ. В форме есть обязательная галочка «Я не робот»;
   ставить её за человека я не имею права, поэтому, скорее всего, пусто именно из-за неё.
   Нужно открыть страницу самому, поставить галочку и искать по ИНН 5040170382; в результате будет кнопка «Выписка».
2. **Реестр СЭЗ Роспотребнадзора** (fp.crc.ru): сайт не открылся, у него сертификат российского УЦ
   (ERR_CERT_AUTHORITY_INVALID), которому этот компьютер не доверяет. Нужно открыть его в браузере
   с установленными сертификатами Минцифры (например, Яндекс Браузер) и искать по ИНН 5040170382.
3. **Госуслуги**: публичного поиска по реестру лицензий без входа нет, а выписка заказывается из личного кабинета.
