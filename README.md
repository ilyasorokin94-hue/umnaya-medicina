# Умная Медицина. Стоматология

Макет нового сайта стоматологии «Умная Медицина» (Удельная, ул. Громова, 10/2): коммерческая главная-одностраничник, страницы услуг и врачей, прайс и пошаговая онлайн-запись. Заявки из форм в демо никуда не уходят.

- Превью: https://ilyasorokin94-hue.github.io/umnaya-medicina/ (GitHub Pages из ветки `gh-pages`, она собирается из папки `docs/`)
- Страницы закрыты от индексации (`noindex`, `robots.txt`).

## Структура

| Путь | Что там |
|---|---|
| `src/data.mjs` | все тексты, цены, врачи, акции, отзывы и слоты картинок (`pics`) |
| `src/assets/styles.css` | стили: токены, общие элементы, шапка, блоки главной, окна, внутренние страницы, анимации |
| `src/assets/app.js` | поведение: прокрутка, меню, окна, калькулятор, квиз, запись, анимации |
| `src/images/` | картинки сайта после обработки (`brand`, `clinic`, `old`, `gen2`, `gen`, `doctors`) |
| `src/photos-raw/` | исходники фото до обработки, в сайт не попадают |
| `scripts/build.mjs` | сборка всех страниц в `dist/` |
| `scripts/photos.py` | единая обработка фото из `photos-raw` в `images` |
| `scripts/serve.mjs` | локальный предпросмотр `dist/` |

## Команды

```
npm install
npm run build              # → dist/ (21 страница)
npm run preview            # → http://localhost:8080/
python3 scripts/photos.py  # после добавления фото в src/photos-raw/<папка>/
```

Публикация превью:

```
npm run build
rm -rf docs && cp -r dist docs
git add -A && git commit -m "…" && git push origin main
git branch -D gh-pages; git subtree split --prefix docs -b gh-pages && git push -f origin gh-pages
```

## Дизайн-система

Концепция «спокойная уверенность»: светлые разделы на бумаге и шалфее, тёмные разделы лесного зелёного как акценты, одна шкала отступов и заголовков.

- Цвета: лесной `--ink #0c2410`, бренд `--green #299926` (theme-color um-med.com), бумага `--paper #f5f4ee`, шалфей `--sage-2 #dfe8dc`, золото оценок `--gold`.
- Шрифты: Manrope для заголовков и цифр, Golos Text для текста.
- Отступ раздела `--sec` 72–128 px, заголовок раздела `--h2` 32–60 px, радиус карточек 22 px.
- Кнопки: зелёная (главное действие), светлая на тёмном, контурная (второе действие). Ссылка подчёркнута.
- Списки фактов с галочками (`checks`), хвост блока `cta-box`: оффер, кнопка, строка «Перезвоним за 5 минут».

Правила, которые держим:

- Коммерческий смысл не трогаем: офферы, цены, акции, призывы остаются как есть.
- Круг только для людей (врачи, администраторы); кабинеты и предметы в скруглённых прямоугольниках.
- Без стрелок, нумерации шагов и вопросов, декоративных точек и линий, вращающихся бейджей, картинок по наведению.
- ПроДокторов только в отзывах и на страницах врачей (там же оценка без ссылки), ссылки открываются в новой вкладке. На первом экране ПроДокторов нет.
- В отзывах один акцент ПроДокторов: круглая печать с оценкой; Яндекс Карты и 2ГИС плитками рядом.
- Фото пациентов с узнаваемыми лицами не публикуем.

## Картинки

Приоритет источников: реальные фото клиники, затем лицензированные, затем сгенерированные. Слот в `pics` перечисляет варианты по порядку: сборка берёт первый существующий файл, второй ставит запасным (`data-fb`), если картинка не загрузилась, показывается подпись-заглушка.

- `old/` фото со старого сайта и из сообществ клиники (первый экран, ресепшен, кабинеты);
- `clinic/` фото из 2ГИС и Яндекс Карт (тур по клинике, диагностика);
- `gen2/` серия предметных фото услуг в обстановке клиники (один стиль, руки в перчатках цвета шалфея);
- `doctors/` портреты врачей одной обработки.

## Анимации

GSAP + ScrollTrigger и Lenis из `node_modules`, при сборке копируются в `assets/vendor`.

- Прокрутку сглаживает только Lenis, у всех анимаций по прокрутке `scrub: true`.
- Остались: раскрытие фото из круга и шторкой, лёгкий параллакс внутри рамки, слова заголовков из-под строки, фраза «О клинике» по словам, закреплённый тур по клинике (на телефоне без закрепления).
- Убраны: заставка, магнитные кнопки, бегущая строка, дрейф лент, горизонтальная лента преимуществ.
- При «уменьшить движение» и без скриптов весь контент виден сразу, окна и формы работают.

## Формы

Все формы (`data-lead`) в демо показывают «спасибо». На рабочем сайте обработчик в `app.js` отправляет заявку в amoCRM с названием формы, поводом, страницей и UTM-метками. Окно при уходе показывается один раз за визит, только на компьютере и не раньше чем через 15 секунд.

Цены перенесены с um-med.com/prices/ на 15.10.2026. Акции и сроки ждут согласования с клиникой.
