# Умная Медицина. Стоматология

Макет нового сайта стоматологии «Умная Медицина» (Удельная, ул. Громова, 10/2). Версия 2 повторяет механику одностраничника Lava Dental (lavadental.lv): заставка, анимации при прокрутке, горизонтальная лента преимуществ, работы «до/после», услуги с номерами, команда, прайс по вкладкам, FAQ по темам и отдельная пошаговая онлайн-запись.

- Превью: https://ilyasorokin94-hue.github.io/umnaya-medicina/ (GitHub Pages из ветки `gh-pages`)
- Исходники: `src/data.mjs` (услуги, цены, врачи, тексты), `src/assets/` (стили и скрипты), `src/images/` (логотип, фото, сгенерированные картинки), `scripts/build.mjs` (сборка)
- Анимации: GSAP + ScrollTrigger и Lenis из `node_modules`, копируются в `assets/vendor` при сборке

## Сборка и публикация

Перед первой сборкой нужен `npm install`: сборка переводит фото в WebP (sharp) и сжимает стили и скрипты (esbuild). В `dist/` попадают только картинки, на которые ссылаются страницы, шрифты лежат в `src/fonts` (без Google Fonts). Обычная сборка даёт демо (noindex, полоса «демонстрационный макет»); для боевого домена `PUBLISH=1 SITE_URL=https://домен npm run build` открывает страницы поисковикам и пишет robots.txt с картой сайта. Боевая сборка обновляет даты в карте сайта только у страниц, где поменялось содержание (`scripts/seo-state.json`, его нужно коммитить), и готовит список для IndexNow: с `INDEXNOW_KEY=ключ` кладёт файл ключа в корень сайта, а после выкладки `INDEXNOW_KEY=ключ npm run indexnow` отправляет изменённые адреса в Яндекс.

```
npm install
npm run build              # → dist/
rm -rf docs && cp -r dist docs && git add -A docs && git commit -m "Превью"
git push origin main
git branch -D gh-pages; git subtree split --prefix docs -b gh-pages && git push origin gh-pages
```

Картинки: если файл из `pics` в `src/data.mjs` лежит в `src/images/`, сборка берёт его, иначе подставляет фото с um-med.com или ПроДокторов.

Цены перенесены с um-med.com/prices/ на 15.10.2026. Акции и сроки ждут согласования с клиникой. Страницы закрыты от индексации (noindex).

## Фид «Врачи» для Яндекс Вебмастера

Боевая сборка (`PUBLISH=1`) пишет `dist/feeds/doctors.xml` (YML 2.0), на сайте это https://smartmed.clinic/feeds/doctors.xml; демо-сборка фид не пишет. В фиде врачи со страницами нового формата: ФИО, вводный текст и ссылка на страницу `/vrachi/<id>/`, на каждую специальность врача одно предложение — первичная консультация по цене из `consult` в `src/doctor-pages.mjs` (своих цен у сборки нет). Клиника — карточка стоматологии в Яндекс Бизнесе 62624439627 (номер из `clinic.yandex` в `src/data.mjs`).

- Специальности (только из перечня Яндекса; «детского стоматолога» в нём нет, это «стоматолог» с приёмом детей) и приём взрослых и детей задаёт таблица `feedSpec` в `scripts/build.mjs`. Новому врачу нужны страница нового формата в `src/doctor-pages.mjs` и строка в `feedSpec`, иначе он в фид не попадёт, сборка напишет, чего не хватает. Ошибки, с которыми Вебмастер фид не примет (специальность не из перечня, консультация без точной цены, строка для врача, которого нет на сайте, повтор id или адреса, нет sharp), останавливают боевую сборку, демо-сборка их печатает.
- `feedZeroPrice` в `scripts/build.mjs`: бесплатные консультации уходят ценой 0 ₽. Если Вебмастер не примет 0, поставьте `false`, и у этих предложений не будет цены.
- Дата фида: с `BUILD_DATE` это «BUILD_DATE 00:00», без него время сборки по Москве. В боевой команде ставьте `BUILD_DATE` днём выкладки, иначе и фид, и карта сайта получат старую дату.

Загрузка в Вебмастер (один раз, нужна роль «Редактирование» или «Частичный доступ → Управление фидами»): Услуги и предложения в поиске → Фиды и ошибки → категория Врачи → регион Московская область → YML → в поле «Ссылка на файл с предложениями» https://smartmed.clinic/feeds/doctors.xml → Готово. Проверка обычно занимает до недели; если идёт дольше 10 дней, напишите в поддержку Вебмастера.

Проверка перед загрузкой и после каждой выкладки: `node validate_feed.cjs dist` (скрипт передаётся вместе с патчем фида, в репозиторий не входит; вторым аргументом можно дать путь к другому файлу фида). Он сверяет фид с правилами Яндекса и страницами врачей, цены с правилом клиники (ортодонт 1 700 ₽, детский стоматолог 2 500 ₽, остальные консультации 0 ₽) и условия Яндекса для сайта: на главной и страницах врачей окна не открываются сами (если установлен playwright, ещё и в Chromium), тексты записи не расходятся с ценами, способы оплаты указаны. Код выхода 1 при любой ошибке.
