# Умная Медицина. Стоматология

Макет нового сайта стоматологии «Умная Медицина» (Удельная, ул. Громова, 10/2).

- Превью: https://ilyasorokin94-hue.github.io/umnaya-medicina/ (GitHub Pages из папки `docs/`)
- Исходники: `src/data.mjs` (услуги, цены, врачи, акции), `src/assets/` (стили и скрипты), `scripts/build.mjs` (сборка)
- Сборка: `npm run build`, затем скопировать `dist/` в `docs/`

Цены перенесены с um-med.com/prices/ на 15.10.2026. Акции и сроки ждут согласования с клиникой. Страницы закрыты от индексации (noindex).
